## 1. Sorting Data

Sorting arranges records in a particular order.

Examples:
- Age: Smallest to Largest
- Salary: Largest to Smallest
- Employee_Name: A to Z

**Important:** Sort the complete table so each employee's details remain together.

## 2. Filtering Data

Filtering displays only rows that match selected conditions.

Examples:
- Department = IT
- Department = HR
- Salary greater than ₹35,000
- Age less than 27

Steps:
1. Select a cell inside the table.
2. Choose Data → Filter.
3. Open the appropriate column dropdown.
4. Select the values or conditions.
5. Apply the filter.

Filtered-out rows are hidden, not deleted.

## 3. Custom Filters

Custom filters let users specify conditions.

Examples:
- Number Filters → Greater Than → 35000
- Text Filters → Begins With → A

## 4. Removing Duplicates

Steps:
1. Make a backup copy of the worksheet.
2. Select the complete table.
3. Choose Data → Remove Duplicates.
4. Select the appropriate columns.
5. Confirm the operation.

The five sample employees have distinct records. Therefore, no duplicate employee records are expected in this sample.

## 5. Identifying Missing Values

A missing value is a blank cell where information is expected.

Practice:
1. Add a practice employee with a blank Salary cell.
2. Open the Salary filter dropdown.
3. Select `(Blanks)` if available.
4. Inspect the incomplete record.

Missing values should be investigated before analysis rather than automatically replaced with zero.
