## 🤔 What is Excel Formatting?

Excel formatting changes the appearance of data to make it easier to read and understand. Number formatting can change how a value is displayed without changing the underlying value.

## 🎨 Practical Tasks

### 1. Format the headings

- Select the heading row.
- Apply bold formatting.
- Choose a background fill colour.

### 2. Add borders

- Select the complete employee table.
- Choose Home → Borders → All Borders.

### 3. Format salary values

- Select the Salary column.
- Open the Number Format menu.
- Choose Currency or Accounting and select the Indian Rupee symbol if available.

### 4. Format dates

- Practise entering a date in an appropriate date format.
- Choose Short Date or Long Date from the Number Format menu.

Note: The employee table above does not include joining dates. Add a Joining_Date column if you want to practise date formatting on this dataset.

### 5. Adjust column widths

- Select the relevant columns.
- Double-click a column boundary to AutoFit the contents.

### 6. Save the workbook

Save the practical workbook as `Employee-Data.xlsx`.
